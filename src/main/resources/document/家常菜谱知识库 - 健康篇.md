# 家常菜谱知识库 - 健康篇

#### 减脂期晚餐怎么搭配？

建议「优质蛋白 + 大量蔬菜 + 少量优质碳水」：如清蒸鱼/鸡胸肉 + 凉拌黄瓜/清炒时蔬 + 小半碗糙米饭或红薯。少油少盐，避免油炸和浓芡。控制在 7 分饱，睡前 3 小时完成进食。

#### 控糖人群主食怎么选？

优先：糙米、燕麦、藜麦、全麦面、红薯、玉米。减少：白米饭、白面包、精制糕点。搭配足量蔬菜和蛋白质可减缓血糖上升。每顿主食建议一拳头大小。

#### 高尿酸饮食要注意什么？

少吃：动物内脏、浓肉汤、海鲜（尤其带壳类）、啤酒。适量：瘦肉、豆制品需个体化。多喝水（2000ml 以上/天），多吃低嘌呤蔬菜。急性期以清淡饮食为主，遵医嘱用药。

#### 老人软烂易消化菜谱推荐？

「山药排骨粥」「蒸蛋羹」「豆腐脑」「炖至软烂的萝卜牛腩」「清蒸鳕鱼」。烹饪以蒸、炖、煮为主，避免过硬、过辣、过咸。肉类切小块或打泥，蔬菜切碎便于咀嚼。

#### 常见食材营养搭配建议？

铁吸收：红肉 + 维生素 C 蔬菜（如青椒炒牛肉）。钙吸收：奶制品 + 适量晒太阳。膳食纤维：全谷物 + 多种颜色蔬菜。不要长期单一饮食，每周至少 12 种以上不同食材。
