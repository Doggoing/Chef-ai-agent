# 家常菜谱知识库 - 家常篇

#### 红烧肉怎样做到肥而不腻？

五花肉切 3 厘米方块，冷水下锅焯水去血沫。少油炒糖色（冰糖至枣红色），下肉块翻炒上色，加生抽、老抽、料酒、八角、桂皮、姜片，加热水没过肉，大火烧开转小火炖 50~60 分钟，最后大火收汁。

#### 鱼怎么煎不破皮？

鱼身擦干水分，两面抹薄盐和淀粉。热锅充分预热后倒油，油温够热再下鱼，中火煎 3~4 分钟再翻面，不要频繁翻动。可搭配葱烧、豆瓣或清蒸做法。

#### 炒青菜怎么保持翠绿？

大火快炒，锅要够热。先下蒜片爆香，青菜下锅后迅速翻炒，沿锅边淋少许水产生蒸汽，加盐调味，叶菜 1~2 分钟、根茎类 3~4 分钟即出锅。不要盖锅盖久焖。

#### 炖汤有什么基本原则？

冷水下骨或肉，大火烧开撇浮沫，转小火慢炖。盐最后放，避免蛋白质过早收缩。可加姜、葱、料酒去腥；菌菇、玉米、萝卜等按易熟程度分批次加入。

#### 米饭总是太软或太硬怎么办？

软：下次减少 10~20ml 水或缩短浸泡时间。硬：适当增加水量，浸泡 15~30 分钟再蒸。一般比例：东北大米 1:1.2，泰国香米 1:1，糙米 1:1.5 并延长煮制时间。
